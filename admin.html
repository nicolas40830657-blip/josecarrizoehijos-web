Clases y videos

Elegí el video de Bunny para cada clase, cambiá títulos y decidí cuáles son gratis o están publicadas. Los cambios se ven al instante en la videoteca.

Falta conectar Bunny para ver la lista de tus videos. Hacelo una sola vez:
  1. En Bunny entrá a Stream → Pileteros de confianza → API y copiá la API Key.
  2. En Supabase, proyecto josecarrizoehijos-web → Edge Functions → Secrets → Add new secret.
  3. Name: BUNNY_API_KEY · Value: la clave que copiaste → Save.
  4. Volvé acá y tocá Traer videos de Bunny.
Mientras tanto podés pegar el Video ID a mano en cada clase.
